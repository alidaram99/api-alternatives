Perspective API ends after 31 December 2026. Keep the same request.

Last updated: October 2, 2026

⏳ 90 days left — the old API shuts down December 31, 2026.

Google Jigsaw's Perspective API (commentanalyzer.googleapis.com) is being sunset. The official site says the service ends after December 31, 2026, with no migration path. Every forum, comment section, Discord bot and research pipeline that calls comments:analyze will start getting errors.

This page shows how to keep that code working with a wire-compatible replacement. You send the same POST /v1alpha1/comments:analyze body and get back the same JSON: attributeScores.TOXICITY.summaryScore.value, spanScores, languages, clientToken, and Google-style error envelopes. The scores come from open-source models, so they are close to Perspective's but not identical. See How the scores compare before you switch production thresholds.

What breaks on January 1, 2027

  • Any request to https://commentanalyzer.googleapis.com/v1alpha1/comments:analyze (REST, googleapiclient, the perspective-api-client npm package, the R peRspective package, and so on).
  • Plugins that hard-code that host, such as the Discourse plugin and many Discord moderation bots.
  • Benchmarks and research code that use Perspective's TOXICITY score as a metric.

The migration

Your new endpoint is the Actor's Standby URL, https://dropin-apis--perspective-compat.apify.actor. You authenticate with your Apify API token, either as ?token=… or as Authorization: Bearer …. The Google key= parameter is accepted and ignored.

curl / any HTTP client

bash
# Before: https://commentanalyzer.googleapis.com/v1alpha1/comments:analyze?key=$GOOGLE_KEY
curl -s -X POST "https://dropin-apis--perspective-compat.apify.actor/v1alpha1/comments:analyze?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"comment":{"text":"You are an idiot"},"requestedAttributes":{"TOXICITY":{},"INSULT":{}},"languages":["en"]}'

Python: Google's own google-api-python-client

Keep your Perspective quickstart code. Only the build() call changes: point discoveryServiceUrl at the Actor and pass your Apify token as credentials.

python
import os
from googleapiclient import discovery
from google.oauth2.credentials import Credentials

BASE = "https://dropin-apis--perspective-compat.apify.actor"
APIFY_TOKEN = os.environ["APIFY_TOKEN"]

client = discovery.build(
    "commentanalyzer", "v1alpha1",
    credentials=Credentials(APIFY_TOKEN),  # was: developerKey=GOOGLE_API_KEY
    discoveryServiceUrl=BASE + "/$discovery/rest?version={apiVersion}&token=" + APIFY_TOKEN,
    static_discovery=False,
)
response = client.comments().analyze(body={
    "comment": {"text": "friendly greetings from python"},
    "requestedAttributes": {"TOXICITY": {}},
}).execute()
print(response["attributeScores"]["TOXICITY"]["summaryScore"]["value"])  # 0.01015937

Node.js: the perspective-api-client npm package

The package hard-codes Google's URL and bundles its own copy of axios, so an interceptor on your app's axios has no effect. Attach the redirect to the axios instance the library actually loads, once at startup:

js
const libAxios = require(require.resolve('axios', { paths: [require.resolve('perspective-api-client')] }));
const BASE = 'https://dropin-apis--perspective-compat.apify.actor';

libAxios.interceptors.request.use((cfg) => {
  if (cfg.url && cfg.url.startsWith('https://commentanalyzer.googleapis.com')) {
    cfg.url = cfg.url.replace('https://commentanalyzer.googleapis.com', BASE);
    cfg.headers.Authorization = `Bearer ${process.env.APIFY_TOKEN}`;
  }
  return cfg;
});

// unchanged application code:
const Perspective = require('perspective-api-client');
const perspective = new Perspective({ apiKey: 'unused-but-required-by-the-library' });
perspective.analyze('You are a complete moron', { attributes: ['toxicity', 'insult'] })
  .then((r) => console.log(r.attributeScores.TOXICITY.summaryScore.value)); // 0.99700852

Discourse (discourse-perspective-api)

The plugin keeps the API key as a site setting, but the host is the constant GOOGLE_API_DOMAIN = "https://commentanalyzer.googleapis.com" in lib/discourse_perspective.rb. In a fork, change that constant to your Standby URL and append token=<APIFY_TOKEN> to the request query. The plugin's models (TOXICITY, SEVERE_TOXICITY) and thresholds work as before. We have not run this inside a live Discourse instance. The request and response format is what we tested.

Other wrappers that already accept a base URL (for example GateNLP's Perspective client) only need the URL and the token.

The language is detected automatically when you leave out languages. Other languages get Perspective's standard "does not support request languages" error, so your existing fallback code keeps working. spanAnnotations, scoreThreshold, clientToken and snake_case field names are supported. The limit is 20 KB of text per comment.

How the scores compare

The scores come from Detoxify, open models trained on the same Jigsaw/Civil Comments data family that Perspective came from. They run as quantized ONNX on CPU inside the Actor: unbiased-toxic-roberta for English and multilingual-toxic-xlm-roberta for the other six languages.

  • Clear cases agree. In our tests, abusive text scored 0.99+ and polite text scored under 0.02.
  • Borderline comments can differ from Perspective by a noticeable margin. We have not run a side-by-side calibration against the live Perspective API.
  • If you auto-hide comments at a high threshold (0.85–0.9), you will probably see similar behavior. If you act at low thresholds, run a sample of your own comments through the Actor's batch mode first and re-tune.

FAQ

Is this Google? No. It is an independent service that implements the public commentanalyzer v1alpha1 interface.

Do you store comments? No. Text is scored in memory and discarded.

Latency? The model takes about 10–30 ms per comment on a warm instance. After about 5 minutes without traffic the instance sleeps, and the next request waits a few seconds while it starts.

Why do I need an Apify token? Apify hosts the service and bills per call. The token identifies your account. It is the only new thing your code needs.
