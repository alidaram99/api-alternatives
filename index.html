Keep your code working when the API it calls shuts down

Last updated: October 2, 2026

Three widely used APIs are being switched off between December 2026 and March 2027. Their official successors use different requests and responses, so every integration has to be rewritten. The tools below accept the same request and return the same response shape as the API you already call. You change the host, add an Apify token, and keep your code.

They run on Apify and are billed per use, with no subscription. Each one says clearly what is identical, what is approximate and what is not supported.

Drop-in replacements

Google Perspective API (ends after 31 Dec 2026)

POST /v1alpha1/comments:analyze, with TOXICITY, INSULT, THREAT, PROFANITY, IDENTITY_ATTACK, SEXUALLY_EXPLICIT and SEVERE_TOXICITY, in 7 languages. Google's own Python client works with only the discovery URL changed. Scores come from open models: close to Perspective's, not identical. $1 per 1,000 comments · Migration guide · Apify Store

Azure Content Moderator, text screen (retires 15 Mar 2027)

POST /contentmoderator/moderate/v1.0/ProcessText/Screen, with the same Terms, PII, Classification and Status JSON. It matches Microsoft's own documented example field for field. Category scores are approximate, and custom term lists are not supported. $1 per 1,000 texts · Migration guide · Apify Store

OpenAI whisper-1 (removed 26 Feb 2027)

/v1/audio/transcriptions and /translations, with SRT, VTT, and word and segment timestamps. It works with the official OpenAI Python and Node SDKs by changing base_url and api_key. It uses the smaller open Whisper model (about 4% word error on clear English), with up to 10 minutes per file. $0.006 per minute · Migration guide · Apify Store

How it works

  1. Create a free Apify account and copy your API token.
  2. Open the tool on the Apify Store. For the API replacements, copy its Standby URL.
  3. Point your existing code at that URL and send the token. Pay only for what you use, and set a spending cap if you like.

Nothing you send is stored: comments, texts and audio are processed in memory and discarded.
