Perspective API shutdown: a migration checklist for 31 December 2026

Last updated: October 3, 2026

⏳ 89 days left — the old API shuts down December 31, 2026.

Google's Perspective API stops after December 31, 2026, and Google offers no migration support, so every integration has to move before then (perspectiveapi.com). This checklist takes you from "where do we even call it?" to a tested cutover, whichever replacement you choose.

New Perspective usage and quota requests already ended in February 2026. Treat the quota you have today as the most you will ever get.

The timeline

DateWhat happens

January 1, 2027Calls to commentanalyzer.googleapis.com fail

Checklist

1. Find every caller

  • Search your code for commentanalyzer.googleapis.com, comments:analyze, perspective-api-client, peRspective, discourse-perspective-api and GOOGLE_API_DOMAIN.
  • Check plugins and bots you did not write: Discourse, Discord moderation bots, CMS comment plugins.
  • Check offline uses: research scripts, dashboards and stored scores that assume Perspective's 0–1 TOXICITY scale.

2. Write down what each caller depends on

  • Which attributes (TOXICITY, SEVERE_TOXICITY, INSULT, THREAT, IDENTITY_ATTACK, PROFANITY, SEXUALLY_EXPLICIT, or the experimental ones).
  • Which languages.
  • Which thresholds trigger an action (hide, queue for review, block).
  • Whether anything parses spanScores, languages or clientToken.

3. Choose a replacement

No code changes; same request and JSONA wire-compatible drop-in such as the Perspective drop-in on Apify ($1 per 1,000 comments)
Free, and you can rewrite the call and re-tuneOpenAI's moderation endpoint (omni-moderation-latest, free)

Only the first option keeps the Perspective request and response. The others use different categories and score scales, so thresholds and stored data need re-mapping.

4. Re-tune on your own comments

  • Export a sample of a few hundred real comments, including borderline ones.
  • Score them with both Perspective, while it still works, and the replacement.
  • Compare decisions at your current thresholds, not just raw scores. Adjust thresholds until the hide/review/allow decisions match what you want.

5. Cut over safely

  • Put the endpoint and credentials in configuration, not code.
  • Run both side by side (shadow mode) for a week if you can.
  • Switch before mid-December, not on December 31: holiday change freezes and the final-day rush are real risks.
  • Keep the old code path behind a flag until January, then delete it.

6. After January 1, 2027

  • Confirm nothing still calls commentanalyzer.googleapis.com. Watch your logs for its errors.
  • Update documentation and runbooks that mention Perspective.

FAQ

When exactly does the Perspective API stop working?

Google says the API will no longer be in service after 2026, meaning after December 31, 2026. Plan for requests to fail from January 1, 2027.

Can I still request a Perspective API key or more quota?

No. Google handled usage and quota requests only until February 2026.

Do I have to change my code to replace Perspective?

Only if you switch to a different API, such as OpenAI moderation or Azure AI Content Safety. With a wire-compatible drop-in, you change the host and the credential, and the request and response stay the same.

Will scores be identical after the migration?

No replacement reproduces Google's private models exactly. Open Detoxify models agree on clear cases but can differ on borderline comments. Re-tune your thresholds on a sample of real comments before you cut over.

What happens if I do nothing?

From January 1, 2027, calls to the Perspective API fail. Depending on your error handling, comments may then be published without screening or not published at all.
