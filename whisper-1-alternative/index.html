whisper-1 is removed on 26 February 2027. Keep SRT, VTT and word timestamps.

Last updated: October 3, 2026

⏳ 146 days left — the old API shuts down February 26, 2027.

OpenAI's deprecations page schedules whisper-1 for removal on February 26, 2027. Its successors are not drop-in. Apps built on whisper-1 features have to change: subtitles through response_format=srt or vtt, timestamp_granularities[]=word and segment, and /v1/audio/translations.

This page shows how to keep exactly that API: POST /v1/audio/transcriptions and /v1/audio/translations, the same multipart fields, and the same json, text, srt, vtt and verbose_json responses. It works with the official OpenAI SDKs. You change base_url and api_key, and nothing else.

Python: official openai SDK

python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://dropin-apis--whisper-compat.apify.actor/v1",   # was: default api.openai.com
    api_key=os.environ["APIFY_TOKEN"],           # your Apify token, sent as Authorization: Bearer
)

with open("armstrong.ogg", "rb") as f:
    srt = client.audio.transcriptions.create(model="whisper-1", file=f, response_format="srt")
print(srt)

with open("armstrong.ogg", "rb") as f:
    verbose = client.audio.transcriptions.create(
        model="whisper-1", file=f, response_format="verbose_json",
        timestamp_granularities=["word", "segment"],
    )
for w in verbose.words[:5]:
    print(f"{w.start:6.2f}-{w.end:6.2f}  {w.word}")
print(len(verbose.segments), "segments,", verbose.duration, "seconds")

Pass the token only as api_key. If you append ?token=… to base_url, the SDK adds the route after the query string and the request goes to the wrong URL.

Node.js: official openai SDK

js
import fs from 'node:fs';
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://dropin-apis--whisper-compat.apify.actor/v1',
  apiKey: process.env.APIFY_TOKEN,
});

const vtt = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('armstrong.ogg'),
  response_format: 'vtt',
});
console.log(vtt); // WEBVTT ... 00:00:15.000 --> 00:00:18.000  That's one small step for man.

curl: word timestamps

bash
curl -s "https://dropin-apis--whisper-compat.apify.actor/v1/audio/transcriptions" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -F model=whisper-1 \
  -F response_format=verbose_json \
  -F 'timestamp_granularities[]=word' \
  -F file=@armstrong.ogg

The response is OpenAI's verbose_json shape: task, language ("english"), duration, text, words[] (word, start, end) and usage ({"type":"duration","seconds":25}). segments[] is included when you request segment granularity, which is the default.

Limits: read before switching

  • Model: Whisper small (multilingual) running with faster-whisper/CTranslate2 int8 on CPU, beam size 5. OpenAI's whisper-1 is the much larger Whisper V2. On clean English (LibriSpeech) we measured about 4% word error rate. Expect more errors on noisy audio, heavy accents and less common languages.
  • Length: up to 10 minutes and 25 MB per request. Longer files get 400 audio_too_long, so split them first, for example ffmpeg -i in.mp3 -f segment -segment_time 540 out%03d.mp3.
  • Speed: about 4 seconds of audio per second of compute. A 1-minute file takes about 12 s and a 10-minute file about 2.5 min. Each instance handles one file at a time. A busy instance answers 429 rate_limit_exceeded, which the OpenAI SDKs retry automatically.
  • Cold start: after about 5 minutes without traffic the instance sleeps, and the next request waits a few seconds extra.

Pricing

$0.006 per minute, billed per started 15 seconds ($0.0015 per 15 s). OpenAI billed whisper-1 at $0.006 per minute rounded to the second, so the two prices match on whole 15-second blocks. A clip under 15 seconds costs $0.0015 here instead of about $0.001. Failed requests are not charged. If you set a spending cap, a file the remaining budget can't cover is refused before it is transcribed (429 insufficient_quota).

FAQ

Is this OpenAI? No. It is an independent service that runs OpenAI's open-source Whisper model (MIT license) behind the same API shape.

Do you keep my audio? No. Audio is decoded in memory, transcribed and discarded.

Languages? All 99 Whisper languages, with auto-detection. Passing language (ISO-639-1) improves speed and accuracy.
